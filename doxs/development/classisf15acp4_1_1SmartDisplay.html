Detailed Description

template<typename SpiType>
class isf15acp4::SmartDisplay< SpiType >

High-level driver for NKK SSD1331-based SmartDisplay modules.

Supports ISF15ACP4 (96x64 frameless pushbutton), ISC15ANP4 (64x48), and ISC01P (52x36 display). Communication uses SPI with separate D/C and SS lines.

Template Parameters
SpiTypePlatform adapter implementing SpiInterface CRTP contract.

◆ Initialize()

template<typename SpiType >
bool isf15acp4::SmartDisplay< SpiType >::Initialize ( bool enable_vcc = true)
noexcept

Perform power-up, reset, and SSD1331 initialization.

Sequence:

  1. Ensure SPI/GPIO ready
  2. Hold RES low >= 3 us, then release
  3. Optionally enable VCC rail via VccEnable pin
  4. Transmit variant-specific initialization table
  5. Configure default memory window
Parameters
enable_vccWhen true, asserts VccEnable after reset.
Returns
true on success.
